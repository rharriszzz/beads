# R334 development evidence

These epochs are preserved to make the selected method and failures auditable.
They are not additional accepted corrections or independent accuracy trials.

- `R333-dom-inspection.json` and the two named-panel screenshots record the actual R333 photographs, expanded keys and local-number resolution.
- `misplaced-*` retain native/context crops, the original local key and pixel inspection for the distinct yellow/black bodies.
- `initial/`: early RGB-body method and an unsafe empty material-component fallback. The fallback could select background; it was rejected and never supplies the authoritative location.
- `shoulder-v2/`: grown reflection-shoulder exclusion and an earlier material representative. Superseded by the measured `(2076,845)` support and the intensity-first pipeline.
- `pre-black-first/`: RGB-body classifier/analysis before the maker clarified the required execution order. Superseded.
- `black-first-gray-v1/`: intensity-first luminance-only trial. Dark chromatic material could pass; the selected method adds conservative maximum-channel darkness requirements and abstention.
- `black-first-channel-v2/`: all-channel trial before removing unused red/yellow inference for black/unknown targets. Selected code now executes those votes only for not-black targets.
- `lda_explore.py`: alternative appearance-feature exploration, not adopted.
- `location-export-failure/`: an inline-comment edit left a location variable undefined; implementation corrected before successful output.
- `export-failure/`: duplicate CSV metadata keyword; source/partial output retained. Fixed in selected exporter.
- `review-export-failure/`: NumPy integer JSON serialization failure; source/partial assets retained. Fixed by explicit scalar conversion.

Only the top-level R334 code, maker ledger and authoritative overlay are selected.
All extra automatic classifications remain provisional. Historical R330–R333 files remain unchanged.
