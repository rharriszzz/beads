The target is **R332-R-0037-0040**, native support (2301.35,1430.23), proposed
AB=(37,40), A index 499, pattern residue 83. Its source says “original RGB,
multiply predicted vacant cell.” R332 admitted it as a working observation, not

|---|---|
| target → C-2300-1458 | (1,0) |
| target → E5-2279-1442 | (1,−1) |
| REC266-P068073 → target | (0,1) |

1. **Withhold color only, as in R347.** There are still 1,059 archived active
   observation records, 1,041 indexed nodes and 2,290 links. Only 1,040 indexed
   pigment observations enter the assessment. The target's red is historical;
   its selected yellow, explicitly dependent on the reconstruction, supplies no
   independent color evidence. Identity/XY/AB/links remain working hypotheses.
2. **Treat identity as uncertain.** Keep the image cue and its provenance, with
   candidate identity/site/links explicitly tentative. This is not just a color
   null: without a distinct body, occupancy, counting and neighbor constraints
   cannot be treated as established. For a conservative sensitivity calculation,
   quarantine those constraints. The archive retains 1,059 records, while the
   hypothetical active graph has 1,040 indexed nodes and 2,287 links. Keeping
   several alternative identities probabilistically would require specifying
   those alternatives; the saved export supplies no calibrated probabilities.
3. **Delete the node and its incident edges in a hypothetical graph.** This
   derived graph has 1,058 records, 1,040 indexed nodes and 2,287 links. The raw
   source and historical graph remain untouched. This operation may affect
   propagation even when color-only withholding does not. It is tested below.

None of these operations implies that a neighboring body inherits the target's
features or that the target is proved nonexistent. The maker's instruction is
an evidence-quality exclusion, not a new alias or physical identity judgment.

## What can be established without rerunning inference

We rebuild adjacency from the saved primitive edge deltas, removing the node and
all three edges for case 3. Breadth-first integration from the existing reference
provides integer coordinates on a spanning tree. Every non-tree edge closes a
cycle; its displacement need not be zero on this cylindrical lattice. We derive
the integer subgroup generated by these displacements **without supplying H to
the calculation**, and then compare it with the saved H.

| Static graph property | Saved R344 graph | Hypothetical removal |
|---|---:|---:|
| Indexed nodes | 1041 | 1040 |
| Links | 2290 | 2287 |
| Connected components | 1 | 1 |
| Independent graph cycles, E−V+1 | 1250 | 1248 |
| Derived cycle-displacement generator | (214,201) | (214,201) |

The three former neighbors remain connected to each other by paths of one, two,
and one edges, all avoiding the target. The certificate supplies their exact
steps and a closed cycle whose sum is ±(214,201), also avoiding the target.
All remaining saved coordinates are recovered modulo this generator, after
aligning the reference origin. Thus the node is not an articulation point and
its relationships are not essential to the **retained graph's** relative lattice
or winding constraints. Graph cycle counts are bookkeeping redundancy, not counts
of independent photographic observations or human confirmations.

There is also a historical independence check: the target is absent from R328's
observation set, while [R328's summary](../r328/results/summary.json) already
records H=(214,201). R332's completion code explicitly preserves baseline
coordinates and H. This target therefore did not cause the original selection
of that winding. It does not follow that the original winding was physically
correct; coherent alternative row histories remain a separate issue.

The retained color set is exactly the R347 assessment's set: Q1 contributes no
color; Q2/Q3 carry the maker's photo-based yellow judgments. Therefore the
pattern remains **201 supported / 0 conflicting / 7 insufficient**, with all
208 residues observed and 1040/1040 retained agreement. Rechecking every divisor
below 400 for the two fixed family/count conventions again leaves only A/208.
All 21 rejected cases have explicit contrary-color witnesses avoiding Q1.
This confirms conditional uniqueness after node deletion, rather than assuming
that color withholding and graph deletion are equivalent.

## What the static test cannot establish

The remaining edge families are held fixed. A connected graph with consistent
integer labels can still follow a wrong photographic row. Neither the closed
cycle nor the agreement count independently certifies body ownership, exact
physical topology, count, geometry or the original chart.

R332's `Completion.model()` fits local geometry from nearby indexed anchors;
`accept()` changes occupancy and `rebuild()` updates neighbor searches. Removing
an admitted cue before that procedure ran might change later rejected/provisional
proposals or their local fits. The saved R332 accepted-addition records name Q1
as an anchor in **zero** accepted additions, but in four provisional records and
52 remaining candidates. These lists are in the certificate. They are direct
recorded dependencies, not a proof of the absence of all indirect effects, such
as occupancy exclusions, blocker checks or earlier competing proposals.

If a counterfactual pipeline result becomes important, the smallest appropriate
test is to remove this cue from the local R332 anchor/occupancy/blocker set,
freeze all unrelated baseline coordinates and photographic measurements, and
reassess the saved affected candidates and any local exclusion decisions. Compare
their sites, admission statuses and incident links before considering propagation
beyond that neighborhood. This would be a new bounded inference test and has
**not** been run here. There is no demonstrated reason to restart whole-necklace
optimization or revise the selected pattern on the basis of the static result.

## Systematic treatment of ambiguous dark edge evidence

Evidence eligibility should be decided by the requested claim. Retain exact pixels
and source IDs even when body identity, pigment or a link is unknown. Require a
visible, distinguishable body and usable native context before an image cue may
enforce counting, occupancy or obstruction. Require an owned material sample
before pigment classification. A reflection is optional body evidence; its
absence neither proves a black bead nor disqualifies a clearly bounded dark body.
Especially ambiguous edge shadow with no usable body/reflection evidence should
abstain before pattern agreement is examined. Exact pixel-distance thresholds
and an all-edge ban would substitute another unreliable proxy for ownership.

When abstention threatens a needed bridge or residue, report that gap and request
a specifically informative view or manual judgment. If exclusion depends on
disagreement with the candidate rather than evidence quality, present results
with and without it and retain the contradiction. Repetition can propose a color
or identify a suspicious record; it cannot manufacture an independent observation.
Here exclusion costs no pattern-residue coverage and no saved-graph connectivity.
