# R298 structural calibration protocol

User authorizes bounded calibration and delivery on photo-2-strategy-v3, superseding
R297 STOP only for this experiment. All old science/photo/feedback/beads.pov frozen
in r298/evidence/preservation.json.gz. No Phase1 output modification, pattern,
production adoption, nonplanar unconstrained axis, or automatic R299.

Three controls precede the joint fit: dimensions with fixed camera/axis; planar axis
with fixed dimensions; shared dimension/axis/camera calibration. Ratios, projected
extents, support displacement and visible gaps stay distinct. Radius fixes the
arbitrary world-unit gauge; image scale is fit to bead diameters as well as width.

Measurements: sixteen geographically distributed native crops selected from existing
large colored supports without model outcomes, analyst-digitized exposed contour
landmarks with explicit 2–4px uncertainty (not calibrated, not maker ground truth).
Photographic transverse profiles across the entire loop reuse the existing learned
paper color, with multiple hue/luminance thresholds, no shadows asserted to be
body edges. Threshold variation, scallops and occlusion remain uncertainty.
Original Phase1 supports and saved separator arcs remain unchanged. Odd/even
geographic blocks provide comparison, never untouched photographic validation.

Forward model: literal rounded hollow annulus and inherited exact first-hit rays.
Planar smooth axis corrections have a substantially wider range than R297 and are
constrained by photographic boundary evidence and curvature, not prior closeness.
Use projected physical surfaces for bounds; never equate image-edge midpoint to
physical axis. Both hands and open/closed/count alternatives survive. Every selected
model requires full-chain nonintersection; collisions and unresolved tests separate.

Budget: controlled sensitivity and low-dimensional least-squares dimension/envelope
fits, then at most 160 local physical/material proposals total. No multi-hour run.
Keep all candidate parameters, failures, paired controls and source fingerprints.
FFT R249 saved primary spectra are diagnostic only, with reciprocal basis inverse
transpose, all assignments and harmonic alternatives; no hand/count constraint.

Review: original unmarked native image, adjustable old/new surface/axis/envelope/
measurement overlays, full-loop signed errors, dimension and +1 comparisons, both
hands, WSL launch.sh opening a browser. Native replay, independent support witnesses,
closure, gauge, evidence/source preservation, browser desktop/narrow/offline checks.
Commit/push/independent remote verification, then STOP for maker review.
