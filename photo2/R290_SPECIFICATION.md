# R290: automatic photographic boundaries and batch review

The complete user request supersedes R289's stop and the partial R290 preparation.
One invocation receives original EXIF-oriented pixels and one independent R289
feature. All scientific evaluation uses this photograph. No generated imagery,
synthetic controls, renderer, physical fitting, indexing or production replacement.
No shape, size, roundness, convexity, solidity or area acceptance gate.

Before detector implementation, freeze a case collection, its original locations,
source hashes, selection rules and development/reserved allocation. Historical
cases are development evidence, never ground truth. Reserved cases must be at
least 110px from development features and are opened only after code/parameters
freeze. The selection script can inspect pixel summaries to select strata; this
is not detector tuning. Every case receives T1–T8, including contradictions and
unavailable measurements. Situation tags are historical observations or selection
proxies, not independently certified labels. Missing coverage must be explicit.

Develop one edge-first seeded graph contour, using short normal/tangential
neighborhoods to measure coherent darkness, valley recovery, contrast and chromatic
discontinuity. Development exposed perimeter bias in the initial separator;
the final graph-resistance solve uses harmonic potential instead of contour length.
An optimizer level set cannot certify a segment.
Never use a window edge as evidence. Expand computational context if contacted;
at the resource limit report unresolved. Preserve supported arcs without closing
unsupported gaps. A competing contour may use the same graph with a modest
regularization change; do not introduce another segmentation family.

Save native candidate masks, exact pixel-edge segments, segment evidence,
centroids only when supported, sensitivity and competing highlight membership.
Statuses: Reliable boundary; Partial boundary / unresolved; Insufficient
measurement. Algorithmic reliability remains provisional until human review.
No reference mask or user judgment enters inference. Black reflections do not
establish dark-body silhouettes or ownership.

Deliver an interactive local browser with native/raw and zoomable photographic
views, thin supported/uncertain arcs, A/B/neither/insufficient/not-sure choices,
highlight ownership questions, navigation, undo/revision history and durable
versioned feedback. Users never trace or paint. Persist exact displayed candidates,
feature IDs, coordinates, image and algorithm hashes with every judgment.

Report status fractions, category coverage, sensitivity, photographic fidelity and
reproducibility. Human correctness, neighbor inclusion/exclusion, duplicate ownership
and centroid accuracy remain unknown without trustworthy reviewed references.
Freeze before reserved inference; no reserved-driven changes. Preserve all initial
failures. Commit, push, independently verify remote, then stop for batch review.
