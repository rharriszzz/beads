# R330 specification

Continue R329 from its frozen observations, photographic bank, saved alternatives,
human-review supplement and colored-material diagnostics. The new user request
authorizes fault-tolerant pattern recovery, bounded photographic correction
experiments, reproducible delivery, commit and push on photo-2-strategy-v3.

Preserve all historical evidence and the existing working graph. Store every new
color, index and path hypothesis separately. No physically absent beads, fabricated
images, assumed count/period, black-highlight centers or automatic truth relabeling.

Implement weighted approximate periodicity and a genuinely different bounded
sequence model. Compare both lattice conventions, both directions, cyclic gauges
and count compatibility. Use distinct observations, geographic held-out sections,
correlated controls, explicit complexity restrictions and real-sequence error
perturbations. Mark exploratory reuse after opening the initial holdout.

Use pattern disagreement to propose photographic inspection. Independently test
color appearance, actual local patch attachment and suffix replay. Prioritize G's
first divergence, H's omitted association, bounded F material/registration tests
and E regression. Patterns must not override contradictory photographic evidence.

Deliver a report, partial motifs with unknowns, conflict IDs/coordinates/indices,
successes and failures, compact matched original-photo comparisons, meaningful
human questions only if necessary, reproduction and independent verification.
Stop after verified delivery; do not imply that a partial pattern is the actual
complete bracelet or that an arithmetic count is photographically reconstructed.
