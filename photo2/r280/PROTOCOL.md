# R280 protocol (written before development)

Compare A local image features, B annular visible-surface evidence, and C B plus
joint pixel-ownership competition. Principal method is C subject to development
measurement. No growth, global fit, identities from old charts, or color pattern.

Use the literal source macro, intended radius, straight 29-site construction,
both hands and separately certified pitch 1.12/1.20. The pitch changes are test
geometry only. Source pitch 1.00 remains an explicitly invalid stress control.
Independent POV identity renders are evaluator-only. Detector inputs contain
predicted geometry rasters generated by Python ray tracing, never identity renders,
true colors, measured segmentation or truth visibility. A1 intentionally receives
correct geometric parameters; A2–A4 receive changed hypotheses. This is an API
separation, not an OS security boundary.

Eight development scenes (seed 280101) and eight untouched held-out scenes
(seed 280202), plus two packing stress scenes. Scene is the statistical unit.
Select thresholds using development positives AND deliberate false predictions;
freeze source and operating rules before held-out evaluation or A5. Report the
entire threshold curve. A failed high-precision gate is a result, never permission
to retune on holdout. Preserve before/after development controls.

Sufficient visibility: at least 30 pixels and >=10% of isolated projected area.
Tiny remnants and fully hidden sites stay separate, with all outputs retained.
A correct strong confirmation must assign >=90% of its measured pixels to the
intended physical body, have >=8 such pixels, and satisfy that body's visibility
criterion. Report other-body contamination and location errors separately.
A false hypothesis accepted as strong counts as a false confirmation even if it
lands on a real neighboring body. Duplicate identities claiming one region must
remain ambiguous. Pose-mismatch trials are recovery trials, not necessarily fake
identities; their correctness is tested against their original intended body.

A2 displacement: 0,.10,.25,.50 projected diameters. A3 size .75/1.25, image roll
+/-20 degrees and camera inclination +15 degrees, one family at a time. No joint
free optimization. A4 paper, neighbor shift, extra midpoint body, duplicate,
wrong phase, wrong scale/orientation with tight uncertainty. Use all sites;
report immediate +/-1/6/7 pairs explicitly, no nearest-centroid oracle pairs.

Frozen R278/R275 evidence remains byte-identical. Synthetic Phase1 comparison
runs the frozen R275 chain and R278 recovery with no geometry and an unrestricted
image domain; historical band initialization is replaced by WholePhoto solely
as domain adaptation. A5 consumes frozen image-only evidence, never old poses,
manual adjacency or historical centerlines. Use local PCA and enumerated source
construction hypotheses, preserving underconstraint. No real accuracy percentage.

## R280 steering — easy-first curriculum

Before any detector results: user prioritizes central, substantially exposed,
well-lit, clearly separated bodies with nearly exact predictions. Establish A1
on these first. Evaluator assigns tiers from independent truth and pixels:
easy requires >=150 visible pixels, >=65% isolated area visible, middle 65% of
projected strip width, 75th-percentile luminance >=.18, and >=1.5px nearest
visible-body separation. Moderate: sufficiently visible but not easy. Hard:
small/hidden or <.08 upper-quartile luminance. Report all tiers independently;
truth tiers never enter inference or acceptance. Development easy A1 gate:
>=90% strong precision and >=60% recall before uncertain-geometry diagnostics.
These finite-sample gates are development criteria, not reliability guarantees.

Development design correction: the first easy stratum was EMPTY because adjacent
projected silhouettes share pixel edges even when 3D surfaces are separated.
Preserved dev-initial-empty-easy-summary.json. Before uncertain trials, replace
minimum silhouette gap with >=.55 diameter distance to every sufficiently visible
body centroid. Use upper-quartile max-channel >=.25 plus luminance >=.05 to avoid
calling illuminated red pigment poorly lit merely because it is red. Other easy
criteria unchanged. This is a development stratum amendment, not untouched
preregistration. Report raw gap and centroid separation; clear-looking separation
still needs visual audit. Holdout definition will be frozen with detector.
