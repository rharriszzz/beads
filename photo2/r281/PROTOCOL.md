# R281 protocol

Compare (A) cross-validated material continuity with newly exposed neighboring
surfaces, (B) differential boundary evidence, and (C) their combination. R280 C
is immutable and is run on the same images and hypotheses. No old manual graph,
chart, fitted pose or reconstructed centerline. Pure R280 geometry/contact and
literal source macro permitted. Frozen Phase1 remains unchanged.

Start with R280's eight present/absent pairs as development diagnostics. New
benchmark: 12 development and 40 fresh held-out scenes, both helicities, intended
radius, analytic separating-plane certification, pitch1.12/1.20 testing geometries.
Select up to four easy substantial central colored targets per scene using the
fixed R280 evaluator tier, independently of detector performance. Save unavailable
slots. Each target has a separate absent render, original prediction unchanged.
Truth is evaluator-only. No observations from the absent render select targets.
No held-out scene is rendered before source/threshold freeze. Scene-cluster
inference, not independent per-pixel/per-bead significance. Position0/.05/.10D,
roll5/10deg separately, no larger error optimization. Both H1/H0 have equal
registration freedom. Negative controls: paper, neighbor shift, wrong phase,
duplicate, wrong unanchored identity. Preserve the unavoidable identical-shape
identity-permutation ambiguity rather than claiming image-only identity recovery.

Freeze operating threshold by development paired present/absent precision-recall:
prioritize >=95% precision with >=50% recall; minimize false confirmation without
hiding positive rejection. If no threshold meets both, report failed gate. Score
curves and all failed variants survive. Other negatives remain separate gates.

Real pilot: one180–240px crop selected solely by automatic Phase1 quality, local
PCA straightness/centrality, >=6 and <=12 substantial reliable colored observations
in its central work window. Raw contextual crop may contain additional bodies.
Select four fitting anchors from one end of the window, retain all others solely
for later review. Fit shared translation/scale/roll/phase, fixed discrete inclinations,
both hands and signed1/6/7 possibilities; no independent bead motion. Save every
alternative and certificate. Predict one or two visible immediate neighbors outside
the anchor assignment using geometry only. Write/hash predictions BEFORE detector
pixels or non-anchor Phase1 comparisons are read in evaluation. Raw photo used
for region quality selection only, not target-specific fitting. No claim that a
location-only split is equivalent to an entirely unseen photograph.

Optional second region is not required; prioritize a carefully evaluated first
pilot and explicit detection-versus-geometry diagnosis. No global fit, indexing,
pattern or reconstruction growth. Stop after documentation, tests, commit/push.

Before the freeze: increased held-out scene count from24 to40 because the fixed
easy selection yielded only23 targets in12 development scenes. No held-out image
was available at this decision. Retain empty scenes in scene-level accounting.
