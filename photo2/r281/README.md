# R281 reproduction and interface

[Report](../R281_PRESENCE.md) · [layered review](../review/r281/index.html) ·
[protocol recorded before the tests](PROTOCOL.md).

Python3.12 in the repository `.venv`; NumPy, SciPy, scikit-image, Pillow,
Matplotlib, POV-Ray3.7. No downloads or historical fitted models needed.
Use `OPENBLAS_NUM_THREADS=1` to avoid small-array thread overhead.

```sh
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m unittest photo2.r281.tests photo2.r280.tests
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m photo2.r281.analyze dev
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m photo2.r281.analyze heldout
.venv/bin/python -m photo2.r281.review
.venv/bin/python -m photo2.r281.audit
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m photo2.r281.recovery_audit
PLAYWRIGHT_BROWSERS_PATH=/tmp/beads-debugger-browsers .venv/bin/python -m photo2.r281.browser_check
```

For a complete replay, set a **new empty** output directory. This reuses the
saved operating freeze, renders both splits and every removed-bead image, runs
both detectors, refits the four real anchors and verifies saved numerical outputs.
It does not recalibrate on held-out data. Expect several minutes.

```sh
R281_OUTPUT=/tmp/beads-r281-replay OPENBLAS_NUM_THREADS=1 .venv/bin/python -m photo2.r281.reproduce
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m photo2.r281.recovery_audit --replay /tmp/beads-r281-replay
```

The second command verifies all 1,230 original synthetic queries (all four
method outputs), decoded present/absent rasters, geometry/truth arrays, and real
freezes/measurements. Development decisions are normalized to the saved rules
because the original development inference preceded calibration. Original
development records remain intact. Historical content hashes are checked against
the fixed R280 base commit, including after R281 has been committed.

The recovery follow-up uses a separate pre-frozen 24-scene confirmation, seed281403.
It compares the unchanged material ablation and combined method after the original
held-out results were already known. To reproduce into another new directory, copy
`results/freeze.json` and `results/confirmation-freeze.json` into that directory,
then run with `R281_OUTPUT` set to it:

```sh
R281_OUTPUT=/tmp/beads-r281-confirmation-replay OPENBLAS_NUM_THREADS=1 .venv/bin/python -m photo2.r281.confirmation run
```

The delivered recovery also verifies all fresh-scene inference outputs from saved
pixels and geometry, without rerendering them:

```sh
R281_OUTPUT=/tmp/beads-r281-confirmation-inference-replay OPENBLAS_NUM_THREADS=1 .venv/bin/python -m photo2.r281.confirmation_replay
```

For the saved results, generate the paired comparison and review with:

```sh
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m photo2.r281.confirmation_summary
.venv/bin/python -m photo2.r281.review
```

Do not run `confirmation freeze` again on the delivered evidence. It refuses to
overwrite the existing freeze. The fresh confirmation uses the same scene family,
not a test of arbitrary materials, black targets, perspective or real-photo accuracy.

The original development sequence was `legacy`, `synthetic dev`, `run dev
--stage basic`, diagnosis/specular-line control, `run dev --stage all`, `freeze`,
`synthetic heldout`, `run heldout --stage all`, and `analyze` for each split.
`real_select` preceded `real_fit`; `real_evaluate` was run only after the detector
freeze and `real/prediction-freeze.json` existed. The one-pixel renderer audit
amendment is explicit in `results/benchmark-amendment.json`. Calibration refuses
an existing held-out directory. The original v1 detector/output survives in
`results/development-v1`; score threshold alternatives survive in calibration.

## Detector interface

`detector.infer(rgb, hypothesis, rules, state=None)` receives image pixels and
geometry only. `hypothesis` supplies target label, projected center/diameter,
H1 and H0 first-surface label maps, unresolved-ray mask, position/angle uncertainty,
and explicit competing claimant IDs. H0 is generated by re-tracing rays with
that single target omitted, keeping all neighboring geometry fixed. Both models
have equal common-pose registration freedom. These maps are **predictions**, not
rendered identity rasters. `geometry.counterfactual` builds them without photograph
or truth I/O. Independent POV identity images are read only in generation validation
and evaluation. Unknown/grazing rays are not forced into background.

Returns H1/H0 scores, margins, all searched registrations and component metrics,
connected supported pixels, H1-favoring and H0-favoring pixels, measured interior
centroid and nominal uncertainty, and supported/ambiguous/contradicted/insufficient.
The physical center remains unmeasured (`None`). Color is not an input or a repeating
pattern prior. The current calibrated score is for easy colored surfaces; this
experiment does not establish a reliable black-body or fine color classifier.

`material` and `boundary` controls change the final score criterion while retaining
combined-model registration and shared support gates. They are ablations, not
independently tuned optimizers. Scores are evidence measures, not probabilities.
H1 support does not prove the identity correspondence of a globally shifted model.

All scenes, masks, parameters, POV files and failed results are retained. Native
review crops preserve original decoded pixels; enlargement is nearest-neighbor.
The R280 source, photograph and Phase1 inventory are unchanged. No new real
Phase1 observations, manual adjacency labels or reconstructed string indices exist.
