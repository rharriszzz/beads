All directories retain original machine-readable results/proposals. They are not
pooled into the delivered final graph or counted as independent truth.

- `display-audit-initial/`: pre-recovery R331 display/baseline omission audit.
  The final `audit/` additionally inventories native-tested cached edge alternatives.
- `initial/`: three-pass fixed-RGB color epoch; rejected as final after photographic
  inspection found shaded yellow material called red. Source snapshot is included.
- `appearance-v2/`: multi-scale learned appearance, baseline-corridor protection;
  final141+ counts do not come from this earlier output.
- `expanded-cache-v3/`: adds retained R266 selected6 candidates and complementary
  black-body geometry. Its1067 indexed /2359-link result was superseded after
  finding off-material cached support representatives. Source is preserved.
- `pre-native-location-final/`: global integrity/novelty outputs for that prior
  epoch and its viewer source. Generated presentation can be recreated from it.
- `native-location-v4/`: selected recovery,127/13/1/0 additions,1041 indexed.
  Re-anchor an off-material cached point only to an actual native-material
  representative, preserve its original coordinate and recheck association.
  Source snapshot, candidate pool and full per-pass proposal ledger are retained.
- `viewer-export-failure/`: exact source before correcting NumPy int serialization
  in optional cached-alternative edge directions. It failed before writing fresh
  viewer data. Scientific results were unaffected. The final browser checker also
  asserts viewer summary equals the final scientific summary to catch stale exports.

Final `results/` adds global integrity, conservative cache overlap/novelty
accounting and complete omission lists. Native remeasurement of retained evidence
is not counted as a new detection merely because its representative moved.
