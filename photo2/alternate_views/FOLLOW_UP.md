# Follow-up work on the bracelet pattern

**Compare the reconstruction with the maker’s original chart first.** If the chart is unavailable, the most useful check with the files already here is an independent reading of the two 104-step paths and the weakest black positions.

## 1. Compare the original chart with the 208-position candidate

Photograph or scan the complete chart, including its color key and any start or direction marks. Have someone transcribe one repeat before showing them the reconstruction. Keep illegible cells marked unknown. Compare the transcription against every cyclic starting position in both reading directions, retaining ties and listing any disagreements by chart cell. A complete match would directly confirm the intended color sequence. A legible disagreement would identify a specific place to check on the bracelet. [Candidate sequence](../r344/provisional-sequence.txt) · [Maker assessment](../r347/answers/ASSESSMENT.md)

## 2. Have a second reader check the most consequential photo evidence

Start with the two paths whose endpoints differ in color at a proposed separation of 104 string positions. Give the reader the original photographs and the starting beads, with the predicted colors and traced steps hidden. Ask them to trace each successive neighbor and record the endpoint colors. Recovering eight steps in each diagonal family and different endpoint colors would independently reproduce the local argument against a 104-position repeat. An ambiguous step identifies exactly where that argument needs a better view. [Wood photograph](../../bead-example-5.jpg) · [White-plastic photograph](../../beads-photo-2-wb.jpg) · [Answer key for comparison after tracing](104-step-pairs.jpg)

For the pigment check, begin with zero-based positions **75 and 140**. Each has only one readable appearance in the alternate views, both on wood. Mix those crops with red, yellow and black controls, hide the chart addresses, and ask the reader to record whether they can distinguish the intended bead and what color they see. Keep an unreadable edge or an uncertain bead identity as unknown. Record which readings agree, conflict or remain unclear before considering any change to the evidence assessment. [Results by position](REPORT.md) · [On-path coordinates](path-results.csv) · [Neighbor coordinates](neighbor-results.csv)

## 3. If the physical bracelet is available, establish which repeat copy was photographed

The current alignments locate a bead within the repeating pattern. The same bead can appear in several photographs. Place a removable reference beside a distinctive point on the loop and photograph consecutive overlapping sections for one circuit, keeping the reference and direction of travel documented. Trace shared beads across each overlap and verify that the last section joins the first. Start with positions 75 and 140 and record which physical sections contain readable examples. This would let the historical three-region support rule use identifiable locations and would provide a direct way to check the proposed 13 repeats. Keep every ambiguous join explicit. [Geographic support rule](../r347/answers/ASSESSMENT.md) · [Current registration limits](REPORT.md)

## 4. If only the existing photographs are available, test fresh sections

The two alternate views cover **125 of 208** positions so far, leaving **83** without a readable check in these views. Choose a few clear windows outside the eight traced paths. Use the beginning of each new path to register it, retain tied registrations, and save their predictions before a second reader examines the remaining beads. Report newly covered positions, correct and contrary predictions, ties, and unreadable beads. If registration stays ambiguous, a longer run of visible neighbors is more informative than another reading of the same endpoint. [Existing paths and holdout results](REPORT.md)
